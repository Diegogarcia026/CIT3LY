Sistema de citas/reservas (CIT3LY)



Descripción del proyecto



Este repositorio documenta el desarrollo del Sistema de citas/reservas CIT3LY, un proyecto que busca digitalizar y organizar los procesos de citas, reservas y administración de estas para todo tipo de organización y/o empresas.

Cómo colaboramos en este repositorio



\- Rama main: contiene la versión integrada y estable del trabajo. No se trabaja directamente sobre ella.

\- Ramas de trabajo: cada integrante crea su propia rama para una tarea específica (ej. docs/requisitos, docs/guia-equipo).

\- Commits: se usan mensajes claros en formato tipo(scope): cambio realizado.

\- Integración: antes de fusionar a main, se revisa que la rama esté actualizada para evitar conflictos.

\- Sincronización: cada integrante trabaja desde su copia local, usando clone, pull y push.
